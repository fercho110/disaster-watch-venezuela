# Disaster Watch Venezuela — Redesign Package

This package contains the visual and content blueprint for converting the existing Vite + React deployment into a more child-friendly, visual and interactive English Unit 4 project.

## Main files
- `docs/CLAUDE_MASTER_REDESIGN.md` — full implementation instruction
- `docs/ENGLISH_COPY.md` — final short English copy
- `docs/UNIT4_ALIGNMENT.md` — scope and vocabulary rules
- `docs/ASSET_MAP.md` — where each visual belongs
- `content.json` — machine-friendly content data
